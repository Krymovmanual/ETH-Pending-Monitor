# Treasury Operations Center v14

This release extends the institutional Overview design across the complete product.

## Interface

- Shared persistent navigation for Overview, Accounts, Wallets, Transfers, Networks, Market and Security.
- Consistent DM Sans and IBM Plex Mono typography across authenticated pages and sign-in.
- Unified graphite-and-green visual system for panels, data tables, controls, badges and dialogs.
- Purpose-specific page titles for Wallets, Network Operations and Market Intelligence.
- Responsive mobile navigation and layouts without changing feature behavior.

## Security experience

- Rebuilt Security & accounts as a structured two-column control center.
- Redesigned sign-in, registration and recovery screen with clearer trust signals.
- Existing authentication, 2FA, encrypted exchange credentials and API behavior remain unchanged.

## Compatibility

- Cache version advanced to v14.
- Existing exchange connections and user data require no migration.
