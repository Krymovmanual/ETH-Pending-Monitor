# Paseqa Treasury v21.2 — Focused Solana Balances

## Wallet display

Every configured Solana wallet displays exactly three balance cards:

- `SOL`
- `USDT · SOL`
- `USDC · SOL`

USDT and USDC are matched by their official Solana Mainnet mint addresses, not by an untrusted token symbol. Unknown SPL and Token-2022 assets are excluded from the API response and UI. Missing USDT or USDC accounts display a zero balance.

## Deployment

No database migration or new Railway variable is required. The release uses asset cache version `21.2.0`.
