# Paseqa Treasury v21.1 — UI Stability

## Included

- Self-hosted DM Sans (400–600) and IBM Plex Mono (400/500) assets.
- Strict `style-src 'self' 'unsafe-inline'` and `font-src 'self'` CSP with no Google Fonts dependency.
- Preloaded primary fonts to reduce first-render font changes.
- Fixed transaction-table column widths and consistent 64 px data rows.
- Stable two-row transaction controls and reserved synchronization-status space.
- Incremental `Age` updates without recreating unchanged transaction rows every second.
- Asset cache version advanced to `21.1`.

## Deployment

Deploy the complete repository to Railway as usual. No environment variables or database migration are required. After deployment, a normal reload is sufficient because the CSS and JavaScript asset URLs use the `v=21.1` cache key.
